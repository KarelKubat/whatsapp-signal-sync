# Usability

When a message gets forwarded from WhatsApp to my Signal account, it arrives in a new chat called `Note to Self`. 

1. If it is possible, make that appear in my personal chat, not `Note to Self`. If that is not possible, make it appear in a chat named `Whatsapp Signal Sync` to match the project.

Also check the other way around: what happens when someone chats me on Signal and I see it on WhatsApp?
